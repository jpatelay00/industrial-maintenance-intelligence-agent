IMIA

Industrial Maintenance Intelligence Agent

An evidence-grounded AI assistant that investigates industrial equipment problems using technical documentation and maintenance history.

View Source Code Watch Demo

The Problem

Industrial maintenance troubleshooting often requires technicians to search through manuals, fault codes, procedures, and previous maintenance records before identifying a likely cause.

IMIA combines these information sources into a structured AI-assisted investigation instead of providing an unsupported chatbot answer.

The Solution

Evidence-Grounded Investigation

IMIA retrieves relevant evidence from uploaded technical documentation and connects that evidence to potential causes.

Show Me Why

Each potential cause can reference the specific evidence supporting the investigation.

Maintenance History

Historical maintenance records provide additional context without being confused with technical documentation.

Local AI

The prototype uses Ollama and a local Llama model, demonstrating a path toward private enterprise deployment.

How IMIA Works

Problem Description → Technical Manual → Evidence Retrieval → AI Investigation → Evidence-Backed Causes
Maintenance History → Historical Context → Investigation Report

Prototype Scenario

The prototype investigates an industrial motor and VFD scenario. The reported problem is that the motor shuts down after approximately ten minutes of operation.

Equipment

MTR-204
Three-phase induction motor
VFD-204
480 V AC

Historical Evidence

A previous maintenance record reports an OVERLOAD fault in the VFD fault history.

Investigation

IMIA retrieves relevant technical evidence and presents potential causes with supporting evidence IDs.
